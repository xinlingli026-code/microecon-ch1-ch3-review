Chapter 1

第一章 经济学概论

研究对象：资源的稀缺性、选择与利用 · 微观与宏观 · 研究方法 · 发展简史

第一节 经济学的研究对象

1
“经济”的含义（三层）
① 金钱、收入；② 节约、节省、有效率；③ 社会生产、分配、交换、消费等活动以及组织这些活动的制度。
文化背景中国古语“经世济民”“经邦济国”，西方“经济”最初指 household management（家政管理）。
2
经济学名称与内容的演变：古希腊色诺芬《家政管理》→ 1615 法国蒙克莱田《献给国王和皇后的政治经济学》→ 1776 亚当·斯密《国富论》→ 1936 凯恩斯《通论》→ 1948 萨缪尔森《经济学》。
3
两大理论体系：马克思主义政治经济学研究社会经济制度与生产关系的发展规律；西方经济学研究稀缺资源的合理配置和充分利用。

一、经济学的研究对象：稀缺性—选择—利用

  • 资源的稀缺性：相对于人类欲望无限性的资源的有限性。
  • 欲望无限：清人《解人颐·不知足》——“终日奔波只为饥，方才一饱便思衣……”（考试常作引证）。
  • 稀缺性的两层含义：① 资源相对于欲望是有限的；② 资源相对于其他资源是稀缺的（有用途才需选择）。
  • 资源的选择与配置：如何利用既定资源生产各种经济物品以更好满足需要 → 即资源配置问题，包含三个基本问题：
    # 生产什么 / 生产多少（What & How many） → 生产可能性曲线
    # 如何生产（How） → 生产者行为（生产理论、成本收益理论）
    # 为谁生产（For whom） → 要素价格决定与收入分配理论
  • 生产可能性曲线（ PPC）：既定资源和技术约束下，社会能够得到的最大产品组合点的轨迹。曲线内部＝资源配置不合理、无法达到；曲线上的点＝有效率。
  • 资源的利用：如何更好地利用现有稀缺资源生产更多经济物品。资源闲置和浪费的原因：
    经济周期与经济增长
    为什么产量不能始终保持在 PPC 上
    充分就业
    为什么资源得不到充分利用
    通货膨胀
    货币购买力变动对产量的影响
经济学定义（必背）经济学是研究在市场经济制度下稀缺资源配置和利用的一门学科。
制度三分法：计划经济制度、市场经济制度、混合经济制度。

第二节 经济学的基本内容

对比项微观经济学宏观经济学
研究对象单个经济单位的行为（厂商、居民户）整个国民经济活动
解决的问题资源配置问题资源利用问题
中心理论价格理论国民收入决定理论
研究方法个量分析总量分析（个量加总、个量平均）
基本假设市场出清、完全理性、完全信息市场机制不完善、政府有能力调控
基本内容均衡价格理论、消费者行为理论、生产者行为理论、市场结构理论、要素价格决定与分配理论、一般均衡与福利经济学、市场失灵与微观经济政策国民收入决定、经济增长、经济周期、失业、通货膨胀、开放经济、宏观经济政策
微观三大基本假设（高频考点） ① 市场出清（clean market）：价格自发调节下商品、劳动、资本市场供求均衡，资源充分利用。
② 完全理性：生产者与消费者都是完全利己的经济人，按最大化原则行事且知道如何实现。
③ 完全信息：信息足够多、信息分布绝对对称、获取信息不付任何成本。
微观与宏观的区别与联系 区别：研究对象、解决问题、基本假设、研究方法、中心理论 5 点不同。
联系：① 相互补充；② 都以市场经济制度为前提；③ 微观经济学是宏观经济学的基础。

第三节 经济学的研究方法

1. 经济模型与六步法

经济模型：描述相关经济变量之间相互关系的理论结构。典型步骤：

定义变量 → 做出假定 → 提出假说 → 解释与预测 → 检验预测 → 评价与选择（通过检验则接受理论，未通过则拒绝并提出新理论；可修改假定与假说）
  • 内生变量：理论所要解释的变量；外生变量：由理论外因素决定的变量。
  • 存量：某一时点上存在的变量值；流量：某一时期内发生的变量值。
  • 判断存量/流量：① 变量值能否直接相加（存量不能、流量能）；② 是否与时间相关（存量无关、流量有关）。
易错内生/外生变量 ≠ 自变量/因变量。如 Q = a − bP 中，a、b 为常数，P 与 Q 都是内生变量；国家消费政策、收入、消费观念等未在模型中反映的才是外生变量；在该函数中 P 是自变量、Q 是因变量。

2. 实证分析与规范分析

实证分析（Positive analysis）
回答“是什么”的问题，就事论事，不带价值判断。
规范分析（Normative analysis）
回答“应该是什么”的问题，就事论理，以价值判断为基础。

3. 均衡分析与边际分析

  • 均衡分析：假定外界因素已知且固定，研究均衡形成条件。分局部均衡（单个市场、其他条件不变）与一般均衡（各市场作为整体，互相影响）。
  • 边际分析：边际是经济变量的增量；边际量是某变量每增加 1 单位引起的其他变量的增加量（如边际成本 = 产量每增 1 单位引起的总成本增加量）。

4. 静态、比较静态与动态分析

方法含义关注
静态分析不考虑时间因素和达到均衡的过程，只在一定假设下分析某均衡状态形成的条件条件
比较静态分析原有条件变化后，把变化后的静态均衡结果加以比较比较
动态分析引入时间因素，分析从原均衡过渡到新均衡的过程过程

第二章 供求理论与均衡价格

需求理论 · 供给理论 · 均衡价格理论 · 弹性理论及其运用

第一节 需求理论

1
需求的含义：在某一时期内，在每一价格水平上消费者愿意购买而且能够购买的某种商品的数量。三个要点：① 专指某一种商品；② 描述价格与需求量之间的反方向关系；③ 是购买欲望与支付能力的统一，是现实需求而非潜在需求。
2
需求曲线：表示商品价格与需求量之间反方向变化关系的曲线，向右下倾斜。
D = f(a, b, c, d, …)　一般需求函数
D = f(P)　　　　　 线性：D = a − bP　或　D = aP − b　（a、b 为正的常数）

影响需求的因素（7 条，方向务必记牢）

因素方向说明
1. 商品本身价格反方向价格升→需求降
2. 相关商品价格视关系互补（汽车–汽油、羽毛球–球拍、手机–充电器）：反方向；替代（猪肉–鸡鸭鱼、肥皂–洗衣液）：同方向
3. 消费者收入视商品正常商品：同方向；劣质商品：反方向；基本生活必需品基本不变
4. 消费者偏好同方向差异小的商品为何要打广告？
5. 对未来的预期同方向未来收入、支出、商品价格的预期
6. 人口数量与结构结构化人口与必需品同方向；结构变动影响需求结构（老龄化→老龄用品需求增加）
7. 政府的消费政策同方向—
其他—气候、节假日、意外事件（疫情→口罩/消毒酒精/防护服；情人节→玫瑰/巧克力）
需求定理与例外 需求定理：其他条件不变时，某商品需求量与其价格反方向变动（价格升→量减）。
例外：吉芬商品——价格上涨反而需求量增加（如某些劣质品）。

第二节 供给理论

1
供给的含义：在某一时期内，在每一价格水平时厂商愿意而且能够供应的某种商品数量；是供给欲望与供给能力的统一。
2
供给曲线：价格与供给量同方向变化关系，右上倾斜。
S = f(a, b, c, d, …)　一般供给函数
S = f(P)　　　　　 线性：S = −c + dP　非线性：S = λPβ　（c、d、λ、β 为正的常数）
影响供给的因素方向说明
1. 商品本身价格同方向价格升→供给增
2. 相关商品价格视关系互补：反方向；替代：同方向；同资源生产（大米–小麦、军工–民用）：反方向
3. 生产技术状况同方向技术进步提高供给
4. 生产要素价格反方向要素涨价抬高成本
5. 厂商对未来预期视情况乐观预期→当期减少供给、扩大生产规模→未来供给增加；悲观反之
6. 政府经济（产业）政策视政策鼓励投资生产（减税、5G/新能源/AI/互联网/大数据/特高压/城际高铁）→供给增；限制（纺织、钢铁、水泥、化工）→供给减
供给定理与例外 供给定理：其他条件不变时，供给量与价格同方向变动。
例外：劳动力的供给（工资提高，劳动供给可能下降——麦格雷戈 X 理论：替代效应 vs 收入效应）、土地、文物、艺术品的供给（价格提高，供给量几乎不变）。

第三节 均衡价格理论

  • 均衡价格：某种商品供给与需求相等时的价格；对应的需求（供给）量即均衡数量。
  • 形成过程：P > P₀ → 供过于求 → P 下降、Q 趋均衡；P < P₀ → 供不应求 → P 上升、Q 趋均衡。现实中的工资（劳动市场）、利率（资本市场）都是市场均衡价格。
均衡求解：Qd = Qs　→　解方程组得 P₀ 与 Q₀
例：Qd = 22 − 5P，Qs = −5 + 4P　⇒　22 − 5P = −5 + 4P ⇒ P = 3，Qd = Qs = 7

供求定理（核心结论）

情形均衡价格 P₀均衡数量 Q₀
供给不变，需求增加（D 右移）上升增加
供给不变，需求减少（D 左移）下降减少
需求不变，供给增加（S 右移）下降增加
需求不变，供给减少（S 左移）上升减少
供求定理供给不变 → 需求变动引起 P、Q 同方向变动；需求不变 → 供给变动引起 P 反方向、Q 同方向变动。

供给与需求同时变动（9 种情形，务必背下符号）

同方向变动
S↗ > D↗P₀↘，Q₀↗
S↗ = D↗P₀不变，Q₀↗
S↗ < D↗P₀↗，Q₀↗
S↘ > D↘P₀↗，Q₀↘
S↘ = D↘P₀不变，Q₀↘
S↘ < D↘P₀↘，Q₀↘
反方向变动
S↗ > D↘P₀↘，Q₀↗
S↗ = D↘P₀↘，Q₀ 不变
S↗ < D↘P₀↘，Q₀↘
S↘ > D↗P₀↗，Q₀↘
S↘ = D↗P₀↗，Q₀ 不变
S↘ < D↗P₀↗，Q₀↗

政府对价格的干预：价格政策

① 支持价格（地板价格，Price Floor）
政府规定的高于均衡价格的最低价格（如农产品价格、最低工资标准）。
结果：供过于求，过剩供给 Qs − Qd。
解决：① 收购（增加库存或出口）；② 补贴生产者；③ 限制种植面积。
积极稳定和支持农业发展　消极① 供过于求 ② 增加政府财政支出 ③ 可能引发国际农产品贸易战
② 限制价格（天花板价格，Price Ceiling）
政府规定的低于均衡价格的最高价格，用于战时、灾害等特殊时期及生活必需品。
结果：供不应求。政府须实行垄断经营或配给制（凭票供应，如粮票 1955–1993）。
积极① 保证基本生活需要 ② 有利社会平等与安定
消极① 不利增加供给、不利抑制需求 → 供不应求 ② 易导致“黑市交易”、败坏社会风气

第四节 弹性理论

1. 需求价格弹性 Ed

含义：一种商品价格变动的比率所引起的该商品需求量变动的比率，即需求量变动对价格变动的反应程度。

点弹性：Ed = (dQ / dP) × (P / Q)　　弧弹性：Ed = −(ΔQ / ΔP) × (P̄ / Q̄)
注意：① 是百分比之比而非绝对量之比；② 需求量与价格反方向变化，弹性为负，实务中取绝对值；③ 同一需求曲线上不同点弹性不同，左上方点的弹性大于右下方点；④ 点弹性是弧弹性的特殊情况。
类型系数含义曲线形状典型商品
完全有弹性Ed → ∞既定价格水平下需求无限水平线—
富有弹性Ed > 1需求量变动比率 > 价格变动比率较平坦非必需品、奢侈品、享受性劳务
单位弹性Ed = 1两者比率相等——
缺乏弹性0 < Ed < 1需求量变动比率 < 价格变动比率较陡峭大米、食盐、蔬菜、燃料等生活必需品
无弹性Ed = 0价格无论如何变动需求量都不变垂直线—
影响需求价格弹性的 5 个因素 ① 商品的必需程度：越必需弹性越小（奢侈品弹性大）。
② 商品的可替代程度：替代品越多弹性越大。
③ 在家庭总支出中所占比重：与弹性成正比。
④ 商品使用时间的长短：耐用消费品（时间长）弹性大；非耐用消费品弹性小。
⑤ 商品用途的广泛性：与弹性成正比（用途广→价格涨则大幅削减次要用途）。

2. 需求收入弹性 EI

EI = 需求变动百分比 ÷ 收入变动百分比
类型系数含义 / 曲线
无弹性EI = 0收入如何变动需求都不变；需求收入曲线垂直
富有弹性EI > 1需求变动百分比 > 收入变动百分比；曲线较平坦
缺乏弹性0 < EI < 1需求变动百分比 < 收入变动百分比；曲线较陡峭
单位弹性EI = 1两者百分比相等
负弹性EI < 0需求与收入反方向变动
用收入弹性划分商品类型（必背） EI > 0 → 正常品；EI < 0 → 劣质品；正常品中 EI > 1 → 奢侈品，0 < EI < 1 → 生活必需品。

3. 需求交叉弹性 Exy

  • 含义：相关两种商品中，一种商品价格变动的比率引起的另一种商品需求变动的比率。
  • 互补关系（反方向变化）→ 交叉弹性为负；替代关系（同方向变化）→ 交叉弹性为正；无关商品 → 0。
  • 绝对值越大：互补关系越密切 / 替代关系越强；也可反过来由系数符号判断商品间关系。

4. 供给价格弹性 ES

ES = 供给量变动百分比 ÷ 价格变动百分比　（点弹性、弧弹性计算与需求弹性完全相同）
类型系数含义 / 曲线
完全有弹性ES → ∞既定价格下供给无限；水平线
富有弹性ES > 1供给变动比率 > 价格变动比率；右上倾斜且平坦
单位弹性ES = 1两者比率相等；过原点的供给曲线弹性均为 1
缺乏弹性0 < ES < 1供给变动百分比 < 价格变动百分比；陡峭
无弹性ES = 0价格如何变动供给量都不变；垂直线
影响供给价格弹性的 5 个因素 ① 时期长短（最关键）：短期只能调整可变要素（劳动力、原材料），无法调整厂房设备 → 弹性小；长期所有要素可调 → 弹性大。
② 生产难易程度与生产周期长短：易生产、周期短 → 弹性大。
③ 生产技术类型：资本技术密集型规模难变 → 弹性小；劳动密集型 → 弹性大。
④ 生产要素的供给弹性：要素弹性大 → 产品弹性大。
⑤ 现在产量的大小：产量很小时增产容易 → 弹性大；接近极限时弹性趋于 0。
微观经济学中短期与长期 短期：为了达到一定产量，不能对所有生产要素进行调整的时期；长期：可以对所有生产要素进行调整的时期。

第五节 弹性理论的运用

1. 价格变动与总收益 TR = P × Q

需求弹性价格与总收益关系典型应用
Ed > 1（富有弹性）反方向薄利多销（奢侈品税、电影票定价高）
0 < Ed < 1（缺乏弹性）同方向谷贱伤农（倒掉多余牛奶、通货膨胀下反感物价上涨）
例（富有弹性）：汽车 Ed = 2，P₁ = 10 万 → Q₁ = 1 万，TR₁ = 10 亿；价格降至 P₂ = 9 万 → Q₂ = 1.2 万，TR₂ = 10.8 亿（价降量增，总收益上升）

2. 蛛网理论（cobweb）

  • 提出：20 世纪 30 年代舒尔茨（美）、里西（意）提出，1934 年卡尔多因图形似蜘蛛网而命名。核心命题：供求均衡被打破后，市场力量不一定能自动恢复均衡。
  • 基本假设：① 本期产量决定本期价格 Pt = f(QtS)；② 本期价格决定下一期产量 QSt+1 = f(Pt)。
类型弹性关系价格与产量现实
收敛型蛛网ES < Ed越来越趋于均衡价格与均衡数量—
发散型蛛网ES > Ed越来越远离均衡农产品
封闭型蛛网ES = Ed既不远离也不收敛—
农产品稳定的两大办法 ① 对农产品实行支持价格；② 对农产品实行期货交易——现价低则交易商预期未来涨价而大量购进，推动现价上涨；现价高则相反，从而稳定价格。

3. 政府税收的分担

  • 直接税：对财产和收入征税，纳税人即负税人，不能转嫁。
  • 间接税：对商品和服务征税，纳税人不完全是负税人，可以转嫁；又分从量税与从价税。
  • 从量税的影响：供给曲线垂直向上移动 T，需求曲线不变 → 均衡价格上升、均衡数量减少。
弹性关系负担分配
Ed > ES税额主要由生产者承担；需求弹性越大生产者承担越多；需求完全弹性时生产者承担全部
Ed < ES税额主要由消费者承担；供给弹性越大消费者承担越多；供给完全弹性时消费者承担全部
Ed = ES生产者与消费者平均负担
消费者负担 = 税后购买价 − 税前购买价 = P₁ − P₀
生产者负担 = 税前销售收入 − 税后销售收入 = P₀ − (P₁ − T) = P₀ − P₂
例：Qd = 120 − 4P，Qs = −20 + 3P ⇒ 120 − 4P = −20 + 3P ⇒ P₀ = 20，Q₀ = 40
征税 7 元/单位 ⇒ 新供给 Qs = −20 + 3(P − 7) = −41 + 3P ⇒ 120 − 4P = −41 + 3P ⇒ P = 23，Q = 28
消费者承担 = 23 − 20 = 3 元；生产者承担 = 7 − 3 = 4 元
Chapter 3

第三章 消费者行为理论

效用理论 · 基数效用论（边际效用分析法）· 序数效用论（无差异曲线分析法）· 替代效应与收入效应 · 价格消费曲线与收入消费曲线

第一节 效用理论

1
效用的含义：消费者从某种物品的消费中所获得的满足程度。
效用 vs 使用价值：使用价值具有客观性（商品能满足需要的物质属性）；效用具有主观性，因人、因时、因地而异。
2
基数效用理论（杰文斯、瓦尔拉斯）：效用可计量、可加总，用基数表示 → 分析方法：边际效用分析法。
3
序数效用理论（帕累托、希克斯）：效用作为心理感受不能计量、不能加总，只能表示高低顺序，用序数表示 → 分析方法：无差异曲线分析法。
4
效用理论对传统理论的质疑：① 重新认识交换的意义；② 质疑价值决定价格（不是劳动产品却有价格、价值大价格低、分解劳动难题、价格不必围绕价值轴心波动）；③ 生财之道就是创造效用；④ 边际效用决定价格。
结论：价格由劳动价值与效用共同决定——效用决定价格的上限，生产者成本决定价格的下限。

第二节 基数效用理论——边际效用分析法

总效用 TU = f(X) 或 f(X, Y)；边际效用 MU = 每增加 1 单位该物品消费所增加的总效用
TU = ΣMU；MU > 0 → TU 增加；MU < 0 → TU 减少；MU = 0 → TU 最大
  • 经济商品：增加消费能增加总效用（MU > 0）；经济负商品：增加消费使总效用下降（MU < 0）；经济中性商品：MU = 0。

边际效用递减规律

含义：在一定时期内、其他物品消费量不变的情况下，随着对某种物品消费量的增加，从连续增加的每一消费单位中得到的边际效用总是递减的（再好的美食吃多了也会腻）。

原因：① 生理或心理原因（刺激作用越来越小）；② 物品用途多样性（总是从重要到次要再到再次要安排用途）。例外：配套成龙的商品、嗜好成癖的商品。

消费者均衡

  • 含义：收入和商品价格一定时，消费者消费一定量商品所能达到效用最大化的状态。
  • 三个假设：① 消费者嗜好既定；② 收入既定，且每单位货币的边际效用相同；③ 商品价格既定。
  • 条件：消费者将全部收入用于购买各种商品，且每种商品的边际效用与其价格之比相等。
MUX / PX = MUY / PY = λ（λ = 每单位货币的边际效用）
证明（拉格朗日/边际替代）：对多变量函数求偏导，求某变量偏导时把其他变量视为常量
例：I = 100 元，PX = 10 元，PY = 20 元 → 均衡解 (X = 4, Y = 3)，总效用 29 为最大

边际效用递减规律与需求定理

消费者愿意支付的价格取决于边际效用：MU 大则愿付价格高。MU 递减而货币边际效用 λ 不变 ⇒ 价格下降 ⇒ 需求量与价格反方向变化。

MU = λ × P　⇒　P = MU / λ（MU 递减、λ 不变 ⇒ P 递减）

消费者剩余与生产者剩余

  • 消费者剩余（马歇尔提出）：购买一定数量商品愿意支付的价格总额与实际支付的价格总额之间的差额。图形：需求曲线与价格线之间的面积；随消费量增加，每单位商品的消费者剩余递减。
  • 生产者剩余：生产者愿意供给的价格总额与市场实际价格总额之间的差额（供给曲线与价格线之间的面积）。
  • 社会福利 = 消费者剩余 + 生产者剩余（= 总剩余）。

第三节 序数效用理论——无差异曲线分析法

1
无差异曲线（效用等高线）：两种商品不同数量组合给消费者带来完全相同效用的一条曲线。
2
三个基本假设：① 偏好的完全性；② 偏好的可传递性（A>B, B>C ⇒ A>C）；③ 偏好的非饱和性（“多比少好”，所有商品都是经济商品）。
3
四个特点：① 向右下倾斜，斜率为负；② 同一平面有无数条，离原点越远效用越大；③ 任何两条不相交（否则与“多比少好”矛盾）；④ 一般凸向原点（由边际替代率递减决定）。

边际替代率 MRS

  • 含义：保持总效用不变时，消费者为增加 1 单位 X 而必须减少的 Y 的数量；就是无差异曲线在该点的斜率（作切线求斜率）。
  • 边际替代率递减规律：保持总效用不变时，X 消费不断增加，每增加 1 单位 X 能替代的 Y 越来越少（注意：递减指的是绝对值在减少）。
  • 原因：边际效用递减——X 的 MU 越来越小，Y 的 MU 越来越大。
  • 与曲线形状：MRS 递减 ⇒ 曲线左上段陡、右下段平坦 ⇒ 凸向原点。直线（完全替代）不满足递减；凹向原点不满足递减。
  • 特例：完全替代商品（如纸币与铸币）→ 直线；完全互补商品（如镜片与镜架）→ 直角线。

预算约束线（消费约束线、消费可能线）

I = X·PX + Y·PY　（斜率 = −PX/PY，截距：X 轴 I/PX，Y 轴 I/PY）
变动情形预算线变化
价格不变，收入变动平行移动
收入不变，两种商品价格同方向同幅度变动平行移动
收入不变，一种商品价格不变、另一种变动扇型变动
收入不变，两种商品价格反方向变动摆型变动
收入与两种商品价格同方向同幅度变动不变

序数效用法的消费者均衡

  • 结论：预算约束线与无差异曲线的切点所对应的商品组合就是消费者均衡点。
  • 理由：预算线之外的无差异曲线虽效用高但达不到；之内虽可达到但非效用最大；故均衡必在预算线上，而线上只有切点效用最大。
  • 两个条件：① 均衡点在预算约束线上：I = X·PX + Y·PY；② 切点处两线斜率相等：预算线斜率 = 无差异曲线斜率（MRS）⇒ PX/PY = MRSXY = MUX/MUY。
  • 与基数法比较：MUX/PX = MUY/PY 与 MRSXY = PX/PY 等价，均衡条件相同，只是分析方法不同。

特殊无差异曲线的均衡（易考）

情形均衡点
完全替代无差异曲线斜率 > 预算线斜率 → 均衡点在横轴（只买横轴商品）；斜率 < 预算线斜率 → 均衡点在纵轴；两者相等 → 预算线上所有点均为均衡。称为边界均衡点/角落均衡点
完全互补均衡点为预算约束线与无差异曲线的拐点所对应的商品组合
凹向原点切点是效用最小点，均衡点为边界均衡点（如收藏品）
特殊凸向原点因收入限制或价格与效用之比，只买/只愿买其中一种商品 → 边界均衡点

第四节 替代效应、收入效应、价格效应 · 消费曲线

1. 希克斯的替代效应、收入效应与价格效应（价格下降时）

  • 替代效应：其他商品价格不变时，价格下降的商品相对便宜，消费者用它替代较贵商品而增加对该商品的需求 → 替代效应 > 0（与价格反方向）。分析时假定实际收入不变（效用不变）。
  • 收入效应：名义收入不变时，价格下降使实际收入增加，从而增加对该商品的需求。分析时只看实际收入变化。
  • 价格效应 = 替代效应 + 收入效应，即价格下降引起的需求量增加。
商品类别价格变动替代效应收入效应两者比较价格效应
正常品−＋＋—＋
劣质品−＋−|替代| > |收入|＋
吉芬品−＋−|替代| < |收入|−
易错提醒吉芬商品价格下降，需求量减少，原因就是负的收入效应绝对值大于替代效应——这是需求定理的唯一例外。

2. 价格消费曲线（PCC）与需求曲线

  • 价格消费曲线：收入和其他商品价格不变时，随某商品价格变化形成的若干条预算约束线与若干条无差异曲线的切点的连线；曲线上所有点都能实现消费者均衡。
  • 由 PCC 推导需求曲线：随 X 价格变化，均衡时的需求量与价格反方向变化 ⇒ 需求曲线向右下倾斜；需求曲线上每一点都表示在相应价格下带来最大效用的需求量。

3. 收入消费曲线（ICC）与恩格尔曲线

  • 收入消费曲线：商品价格不变时，随收入变化形成的若干条预算约束线与若干条无差异曲线的切点的连线；曲线上所有点都能实现消费者均衡。
  • 恩格尔曲线：表示消费者收入与某种商品需求数量之间关系的曲线。正常商品向右上方倾斜，劣质商品向左上方倾斜。
  • 恩格尔定律：随着收入不断增加，食品支出在家庭开支中占的比重越来越小，其他方面开支占比越来越大。恩格尔系数越低，生活水平越高。
恩格尔系数与生活水平（标准经验值）59%以上：贫困；50%–59%：温饱；40%–50%：小康；30%–40%：富裕；30%以下：最富裕。2019 年中国为 28.2%。
