## 章节覆盖

1. **第一章 经济学概论** — 研究对象与稀缺性、微观与宏观、基本假设、研究方法（经济模型/实证与规范/均衡与边际/静态与动态）、经济学发展简史
2. **第二章 供求理论与均衡价格** — 需求理论、供给理论、均衡价格理论（含供求定理与 9 种同时变动情形）、价格政策（支持价格 / 限制价格）、弹性理论（需求价格/收入/交叉弹性、供给弹性）、弹性运用（总收益、蛛网理论、税收分担）
3. **第三章 消费者行为理论** — 效用理论、基数效用论（边际效用分析法、消费者均衡、消费者剩余）、序数效用论（无差异曲线、MRS、预算约束线）、替代效应与收入效应、价格消费曲线与收入消费曲线 / 恩格尔曲线
